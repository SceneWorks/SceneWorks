# Shared memory metadata

F-003/F-018/F-019/F-020/F-021 use `sceneworks_core::memory_contracts` for backend-neutral metadata construction. This is arithmetic and contract introspection; it does not execute a model.

The provider authority is inference revision `a43724b82fbae35c9227cef4bcdabba6dd1da12c`, specifically `gen-core/src/generator/descriptor.rs` (`ComponentPrecisionFloor::applies_to`, `effective_component_quant`), `memory_strategy/selection.rs` (`MemoryNumericTier`) and `memory_strategy/contract.rs` (`generation_memory`).

- A component floor applies individually when its `selected_tier` matches the selected quant. Keep matching entries in provider order. Empty tables, unmatched tiers and unquantized selections have no active floors. Both lanes use this rule. At this pin, Mage's two Q4 floors and MLX Wan's one Q4 floor are the shipped partial declarations; registry tests exercise every nonempty declaration on the linked platform. Mixed selected-tier tables are covered independently. The pinned tier type requires a static slice, so mixed subsets are interned once per distinct subset; ordinary uniform tables allocate nothing.
- Candle delegates optimized selections to `contract.generation_memory`. Its resident call-site mapping remains `None`, preserving load defaults even when a contract opts into an explicit resident block. MLX retains its existing `unwrap_or_default` representation.
- Estimate evidence accepts the caller's complete key, including backend, route/family, numeric floors, load shape, mode, reference carrier/count, overlay, geometry, frame rate, engagement and exact parameters. Only implementation and parameter dimensions are satisfied; calibration/history/environment remain missing, loadability unverified, and parity unrun. Captured measurement records keep their original producer revisions and dimensions.
- New runtime and estimate provenance comes from core's `sceneworks-gen-core` dependency declaration. `core/build.rs` compiles it into `inference_provenance::INFERENCE_REVISION`; the capture tooling reads the same declaration. Pin bumps change dependency manifests, without separately rewriting producer stamps. This adds no currency gate and changes no stale-record admission policy.
- The shared parameter builder selects the smallest declared numeric candidate for each engaged mechanism with explicit scope policies preserving existing caller conventions. Missing required domains refuse a candidate. Candle/SenseNova retain the first provider-declared scope, including explicit DiT. MLX image retains implicit DiT. MLX video retains implicit DiT without native-quant phase facts; adopted native contracts select the minimum declared scope (implicit DiT, then text encoder, then both) and the video selector enumerates the complete domain. MLX's semantic decode-quality/route authority remains layered over the shared non-decode builder. Native video allocation still checks its complete phase/format/selection constraints. The shared anchor regime prices only denoiser windows; an encoder-only scope grants no denoiser residency saving. Candle retains its strict refusal of incomplete engaged knobs; MLX retains the unbounded interpretation of absent knobs.

Validation uses metadata, fixtures and arithmetic only. Native macOS compile/lint covers the MLX build; Linux/no-backend and Candle cfg validation remains in the existing CI lanes. No measurement campaign or learned execution is needed for these changes.
