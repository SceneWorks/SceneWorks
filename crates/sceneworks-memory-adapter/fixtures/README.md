# PuLID reference

`pulid-reference.png` is the FLUX.1-dev-generated face from
`SceneWorks/inference` at `e11fd9f0fd26a0eee3a0eb1f4ca7f81c32b5aeb8`,
`docs/migration/evidence/sc-16956/pulid-reference.png`.
That campaign used it successfully for PuLID's production face detector and
identity encoder; see `docs/migration/evidence/sc-16956-flux1-candle-preview.md`
in the same revision. It is bundled unchanged so captures do not depend on an
operator's portrait or another model render. The Candle fixture name includes
`face-sc16956` to distinguish it from the former synthetic gradient.
