# StarVector-1B provenance

SceneWorks installs the immutable
`starvector/starvector-1b-im2svg@380ab95d25a8e9ab1dc825debe238b4953ae13b9` snapshot for
native image-to-SVG generation. The upstream model card declares Apache-2.0 and the snapshot ships
no separate NOTICE file. SceneWorks excludes the repository's Python modules and does not execute
remote model code.
