# StarVector-8B Vectorization Guide

StarVector-8B converts one raster image into SVG source. Choose a clear source with a distinct
silhouette, limited visual clutter, and enough contrast to separate the subject from its background.

This checkpoint is image-conditioned only. SceneWorks does not send free-form text guidance to it,
and the catalog intentionally advertises `image_to_svg` without `text_to_svg`.

The native provider will read the installed immutable snapshot directly. StarVector-8B dispatch
remains disabled until the permanent-pin terminal campaign accepts its exact MLX and CUDA device
classes. If Model Manager reports the model as missing or incomplete, download or repair it while
that terminal acceptance remains pending.

Source: [StarVector-8B image-to-SVG model card](https://huggingface.co/starvector/starvector-8b-im2svg/tree/518beea8dcb5f7a37c5911e92d1d62a76beee7f9)
