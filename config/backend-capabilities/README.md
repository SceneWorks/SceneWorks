# Backend capability matrix

`matrix.json` is the authoritative, mechanically verified MLX/Candle capability inventory. It is
generated by executing the real SceneWorks routing predicates against canonical request shapes and
joining those answers to the shipped model manifest and descriptor-derived preview catalog.

Regenerate it from the repository root:

```text
cargo run -p sceneworks-core --bin dump-backend-capability-matrix -- \
  config/backend-capabilities/matrix.json
```

The matrix covers every shipped manifest model and every GPU `JobType`. Model rows split
operation/mode, conditioning shape, user adapter, precision tier, and preview support; training
kernels and utility jobs have dedicated rows. `sources` contains SHA-256 digests of the manifest,
MLX/Candle scheduler predicates, API validation, worker dispatch, UI gates, and preview facts. The
focused Rust test regenerates and byte-compares the typed document, so drift at any of those seams
requires an intentional matrix update.

Every MLX-only cell names its Shortcut implementation obligation. `authority` identifies the
specialist epic whose contract governs that cell where applicable. Candle-only cells are retained
with `preservedCandleOnly: true` rather than normalized away.

`exceptions.json` is intentionally empty at foundation time: no owner approval was invented.
Future exceptions must provide category, approver, approval date, user-facing behavior, revisit
condition, and exact matrix cell paths. The generator rejects incomplete or duplicate records.
